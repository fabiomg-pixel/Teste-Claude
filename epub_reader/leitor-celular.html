Na estante

Nenhum livro ainda. EPUBs sem DRM — os do Domínio Público e do Project Gutenberg servem bem.

Aponte para o servidor do leitor rodando no seu computador. Posição, fronteira e destaques passam a viajar entre celular, Mac e iPhone — e os livros também. O endereço e o token aparecem no terminal quando você roda python app.py.

Onde ficam os arquivos. No armazenamento do próprio navegador — e, se você ligar a sincronização, também no seu servidor. Fora isso nada sai daqui: quem leva o texto para a conversa é você, colando, e só o pedaço que a página monta.

Chave da API

Para conversar dentro do app, cole uma chave da API da Anthropic (sk-ant-…). Ela fica guardada só neste aparelho, na área privada do app, e vai direto para a API — não passa por nenhum servidor meu.
